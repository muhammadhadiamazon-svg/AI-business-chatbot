# 🤖 AI Business Assistant Chatbot

An interactive AI Chatbot built using Python, Streamlit, and the Gemini API.

## 🚀 Live Demo
You can try out the live chatbot here: [Live App Link](https://ai-business-chatbot-34dybmeyxznujkcunuw2yt.streamlit.app)

## ✨ Features
- Powered by Google Gemini AI
- Conversational chat interface built with Streamlit
- Supports multilingual queries (English, Roman Urdu, Urdu, etc.)
- Fast response generation

## 🛠️ Tech Stack
- **Language:** Python
- **Framework:** Streamlit
- **AI Model:** Google Gemini API
- **Hosting:** Streamlit Community Cloud
